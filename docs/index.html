Telusur.

An internal knowledge assistant for mid-size and large companies. Employees ask in plain language and get answers from company documents, with the page cited, drawn only from documents they are allowed to read. Admins get versioning, an append-only audit log, unanswered-question topics, and a measured evaluation of answer quality.

  • The reranker is the component that matters. It lifts Recall@1 from 0.84 to 0.97 and is the only score calibrated enough to decide "I don't know".
  • Hybrid without reranking was worse than vector alone. Keyword search pulls loosely related passages up; it pays off only as a candidate source for the reranker.
  • Every false refusal was an English question whose right passage was already ranked first; cross-lingual reranker scores were too low. Translating the query before search cut false refusals from 10% to 2%.

  • The load test found two concurrency bugs before any user did: the embedder and reranker shared the GPU without a common lock (the process aborted at 5 users), and requests held a database connection while queued for the GPU (the pool ran dry at 20). Both fixed; 0% errors at 20 users.
  • The reranker is also the throughput ceiling. Halving its candidates buys 54% more throughput for one question in 58 lost at rank 1 — a measured trade-off, exposed as a setting instead of a silent default.

What it shows

Retrieval & answers

  • Structure-aware chunking with page numbers
  • Vector + full-text, RRF, cross-encoder rerank
  • Streaming answers, verified citations, refusal threshold

Enterprise controls

  • Multi-tenant with Postgres row-level security
  • Per-collection and per-document access, enforced in SQL
  • Append-only, partitioned audit log

Quality loop

  • Generated test set + manual verification
  • LLM judge on a separate model
  • Thumbs-down feedback becomes a regression test
